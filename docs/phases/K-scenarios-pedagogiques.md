# Phase K : Scénarios pédagogiques

Objectif proposé : 225 scénarios, 15 par chapitre. Répartition : 3 débutants, 5 intermédiaires, 5 avancés, 2 exceptions. Le catalogue JSON contient 225 emplacements de conception, pas des cas cliniques rédigés.

Chaque scénario validé devra contenir contexte fictif, informations initiales, réponses des PNJ, branches, référence autorisée, version du protocole, verdict attendu, justification et bilan. Les thèmes génériques sont à adapter à chaque chapitre; ne pas inventer une exception ou une règle pour remplir un emplacement. Aucun verdict attendu n'est attribué sans source validée.

Progression : retour explicatif, nouvelle tentative, maîtrise par chapitre; aucun trophée ni classement. Les erreurs motrices ne sont pas des erreurs métier. Tous les verdicts corrects ont la même valeur pédagogique.

Les cas détaillés restent dans un espace autorisé non public. Validation métier et tests de parité entre modes requis. Issue #11 ouverte. Suite : phase L, inventaire des assets.
