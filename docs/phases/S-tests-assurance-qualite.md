# Phase S : Tests et assurance qualité
Priorité : verdicts déterministes, confidentialité, synchronisation, accessibilité, performance. Tests unitaires du moteur à créer : limites, données manquantes, versions expirées, retour arrière, transitions invalides et quatre verdicts. Tests de parité entre modes, événements dupliqués et reconnexion. Les 225 entrées du catalogue sont des emplacements de scénarios, pas des cas métier validés. Chaque cas doit recevoir faits fictifs, source autorisée, résultat attendu et validation humaine avant exécution. Tests structurels Node ajoutés; CI GitHub Actions pour catalogue et compilation web. npm install provisoire jusqu'au verrouillage des dépendances. Tests E2E Playwright, Vitest, Unreal Automation, WCAG 2.2 AA, charge et sécurité restent à implémenter. Critères proposés : zéro erreur critique de verdict, zéro fuite de données, tous les cas approuvés réussis, aucune régression bloquante. Aucun résultat CI ou audit confirmé à ce stade. Issue #19 ouverte. Suite T : déploiement.
