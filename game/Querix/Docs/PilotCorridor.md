# Pilot corridor
Compile the C++ project in Unreal Editor, create a blank level, place QuerixCorridor at the origin and a PlayerStart at (-400,0,100). Configure a GameMode with QuerixCharacter as default pawn. Add lighting and a visible character mesh. The generated blockout is 14 x 10 m with two 1.4 m passages, using engine cubes and collision. Place two Blueprint subclasses of QuerixDecisionDoor at (100,-230,0) and (100,230,0), assign q1 and oui/non respectively. Door visuals, animation, interaction trace, engine response bridge and subsequent rooms remain to implement. Dimensions are fictional, not a surveyed clinic plan. No compiled map or executable has been produced. Archery is superseded and its unused source remains temporarily in history/current tree.
